# GFZ Data Services science topics

These 25 original PNG motifs were downloaded on 2026-09-17 from the existing
[GFZ Data Services homepage](https://dataservices.gfz-potsdam.de/web/).
They are used locally so the ERNIE homepage does not depend on TYPO3 for images.

Original filenames are preserved. For each PNG in this directory the source is:
`https://dataservices.gfz-potsdam.de/web/fileadmin/dataservices.gfz.de/Graphics/honeycomb/<filename>`.

The existing [copyright and image credits](https://dataservices.gfz-potsdam.de/web/about-us/copyrights)
remain linked from the homepage footer. This migration does not assign a new license
to the images. Topic labels and destination filters are defined by `App\Enums\ScienceTopic`.
