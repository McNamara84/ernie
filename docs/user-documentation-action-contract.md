# User documentation action contract

The English action descriptions rendered at /docs are maintained in [docs-actions.ts](../resources/js/data/docs-actions.ts). This table links each visible action to the code that performs it. Update the action description, contextual help, and related tests whenever a button, gate, or API effect changes.

| Action in the UI | Access and record prerequisite | Effect after confirmation or click | Source |
| --- | --- | --- | --- |
| Editor: Save Draft | Signed-in user; Main Title; unpublished record | Saves a local draft; no DataCite request | [Editor](../resources/js/components/curation/datacite-form.tsx) |
| Editor: Validate | Signed-in user; valid required fields | Saves validated metadata in ERNIE; no DataCite request | [Editor](../resources/js/components/curation/datacite-form.tsx) |
| Editor: Register | register-doi gate; no DOI; valid metadata; landing page before remote write | First click only validates and opens a dialog. Confirmation saves locally, prepares a landing page if needed, then creates and publishes a DOI at DataCite. A remote failure can leave the local save intact. | [Editor](../resources/js/components/curation/datacite-form.tsx), [DOI controller](../app/Http/Controllers/ResourceDoiRegistrationController.php) |
| Editor: Update Metadata | register-doi gate; existing DOI; matching DataCite record in the active environment | Confirmation saves locally, then updates the existing DOI at DataCite. No new DOI. | [Editor](../resources/js/components/curation/datacite-form.tsx), [DOI controller](../app/Http/Controllers/ResourceDoiRegistrationController.php) |
| Editor: Preview LP / Show LP | Main Title for preview; published page for Show LP | Preview saves a local draft and opens its preview. Show LP opens the existing page without saving. Neither sends a DOI request. | [Editor](../resources/js/components/curation/datacite-form.tsx) |
| Resources: Edit | Selected resource(s) | Opens editor tabs without saving | [Resources page](../resources/js/pages/resources.tsx) |
| Resources: Set up landing page | manage-landing-pages gate; exactly one selected resource | Opens setup; saving stores landing-page settings locally. No DOI request. | [Resources page](../resources/js/pages/resources.tsx) |
| Resources: Manage Related Items | Exactly one selected resource | Saves relationships locally; DataCite remains unchanged | [Resources page](../resources/js/pages/resources.tsx) |
| Resources: Export DataCite JSON / XML / Export JSON-LD | Selected resources; export limit | Downloads stored metadata without changing resources or DOIs | [Export controller](../app/Http/Controllers/BatchResourceExportController.php) |
| Resources: Register DOI | register-doi gate; exactly one resource without a DOI and with a landing page | After prefix choice and confirmation, creates and publishes one new DOI at DataCite from saved metadata | [Resources page](../resources/js/pages/resources.tsx), [DOI controller](../app/Http/Controllers/ResourceDoiRegistrationController.php) |
| Resources: Update metadata | register-doi gate; each selected record has a DOI and landing page; up to 25 | After confirmation, updates existing DataCite records individually from saved metadata. No new DOI; partial success possible. | [Resources page](../resources/js/pages/resources.tsx), [batch controller](../app/Http/Controllers/BatchResourceRegistrationController.php) |
| Resources: Send review link / Notify changed review link | send-review-links gate; review status and valid preview link | Queues invitation or replacement-link emails; no DOI request | [Review controller](../app/Http/Controllers/ResourceReviewLinkController.php) |
| Resources: Delete | Curator, Group Leader, or Admin; published records require delete-published-resources gate | Removes selected ERNIE records and landing pages. DataCite records remain; a published DOI may resolve to an ERNIE 404 page. | [Resources page](../resources/js/pages/resources.tsx), [resource policy](../app/Policies/ResourcePolicy.php) |
| Resources: legacy imports | importFromDataCite policy; Group Leader or Admin | Imports eligible existing metadata into ERNIE; does not mint a DOI | [Resources page](../resources/js/pages/resources.tsx), [import controller](../app/Http/Controllers/DataCiteImportController.php) |
| Resources: Update DataCite landing-page URLs | update-datacite-landing-page-urls gate; Admin | After preview and confirmation, updates the target URL of existing DOIs; no new DOI | [URL controller](../app/Http/Controllers/DataCiteUrlUpdateController.php) |

The documentation's capability flags come from [DocsController](../app/Http/Controllers/DocsController.php) using the same gates and import policy as the product pages. Record-specific prerequisites are explained within the visible action. Backend authorization still decides whether a request may run. Documentation settings are read for each request so disabled editor features disappear immediately.

## Verification and accessibility

- [Backend documentation tests](../tests/pest/Feature/DocsTest.php) cover gates and setting changes. [Frontend documentation tests](../tests/vitest/pages/__tests__/docs.test.tsx) cover action effects, filtering, search, and deep links. [Editor tests](../tests/vitest/components/curation/__tests__/datacite-form.test-suite.tsx), [resources tests](../tests/vitest/pages/__tests__/resources.test.tsx), and [browser tests](../tests/playwright/critical/docs.spec.ts) cover action behavior and navigation.
- Keep the application and /docs text in English. Use one English page language, semantic headings, a named navigation region, focus transfer for deep links, keyboard operation, 200% zoom, narrow-screen reflow, and a manual screen-reader check.
- For public-sector accessibility, use [BITV 2.0 § 3](https://www.gesetze-im-internet.de/bitv_2_0/__3.html) and the harmonised [EN 301 549 reference](https://www.bundesfachstelle-barrierefreiheit.de/DE/Fachwissen/Informationstechnik/EU-Webseitenrichtlinie/FAQ/fragen-antworten-eu-richtlinie-websites-und-mobile-anwendungen?nn=69281627401de22f3aa2ca90). [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/) is an additional development target.
